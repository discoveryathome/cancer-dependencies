# Novelty and biological-interpretation audit

No new biological relationship is claimed by this pilot. The target panel and the
contributor's two-feature pairs deliberately use familiar biology. A better held-out
predictor is a computational contribution; it does not make its biological association new.
This is an initial literature check, not an exhaustive patent, preprint or publication search.

| Relationship/class | Status for this pilot | Primary evidence/context |
|---|---|---|
| Oncogene mutation/expression and dependency | Established class; positive controls | https://doi.org/10.1038/s43018-024-00789-y |
| SMARCA4 deficiency → SMARCA2 dependency | Established; not a new hypothesis | https://pmc.ncbi.nlm.nih.gov/articles/PMC3958034/ |
| SMARCA2 deficiency → SMARCA4 dependency | Published reciprocal relationship, with context limitations | https://pmc.ncbi.nlm.nih.gov/articles/PMC6691015/ |
| ARID1A alteration → ARID1B dependency | Established; allele/function encoding remains imperfect | https://doi.org/10.1038/nm.3480 |
| STAG2 loss → STAG1 dependency | Established; rare mutation support can limit broad-panel prediction | https://pmc.ncbi.nlm.nih.gov/articles/PMC5514935/ |
| MTAP loss and PRMT5 vulnerability | Published; transfer from partial suppression to full knockout must be tested | https://pubmed.ncbi.nlm.nih.gov/26912360/ |
| TP53-related sensitivity in CRISPR screens | Known biology plus potential assay-specific toxicity | https://doi.org/10.1038/s41467-022-32285-1 |
| EPCAM expression as an EGFR-prediction feature | Exploratory predictive association here; no novelty claim | https://pmc.ncbi.nlm.nih.gov/articles/PMC6177200/ and https://pmc.ncbi.nlm.nih.gov/articles/PMC9454230/ |

For EPCAM/EGFR, existing work connects these proteins and epithelial/mesenchymal state.
That is a reason to consider a biological-state proxy or shared signaling context, not
proof that an observed threshold rule identifies a causal vulnerability. These papers do
not establish that this pilot's exact rule is new or already published. Exact-rule novelty
is unresolved, and a threshold fitted to a particular release is not intrinsically a new
biological mechanism. Evaluate held-out lineage and batch results before pursuing it.

Recent work also includes [gene-dependency-informed response inference](https://doi.org/10.1038/s41467-026-73977-2)
and [organoid dependency mapping](https://doi.org/10.1038/s41586-026-10830-y).
The pilot does not reproduce those methods or claim to beat the state of the art.
The pinned 24Q2 release is chosen for reproducible, clearly attributed open data access,
not because it is the newest available biology.

A future novelty claim requires: a precise feature/allele/context statement; a sourced
search that includes older studies and recent literature; comparison with established
biomarkers; a genuinely untouched cohort; and independent expert review. Suggested
mechanisms remain computational research hypotheses. No wet-lab design is part of this task.
